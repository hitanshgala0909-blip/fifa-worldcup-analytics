# FIFA World Cup 2026 Intelligence Platform — Production Guide

ML-powered match predictions, tournament simulation, player analytics,
and fantasy recommendations for FIFA World Cup 2026.

---

## Quick Start

```bash
# 1. Clone
git clone <repo-url> && cd wc2026

# 2. Backend setup
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 3. Run ML pipeline (once, after model artefacts exist)
python outputs/generate_outputs.py

# 4. Start backend
uvicorn backend.main:app --reload --port 8000

# 5. Frontend setup (new terminal)
cd frontend
cp .env.local.example .env.local    # edit NEXT_PUBLIC_API_URL if needed
npm install
npm run dev                          # → http://localhost:3000
```

## Environment Variables

### Frontend (`frontend/.env.local`)

| Variable | Default | Description |
|---|---|---|
| `NEXT_PUBLIC_API_URL` | `http://localhost:8000` | FastAPI backend URL (no trailing slash) |
| `NEXT_PUBLIC_SITE_URL` | `http://localhost:3000` | Your deployed site URL (for sitemap) |

### Backend (`.env`)

| Variable | Default | Description |
|---|---|---|
| `WC2026_BASE_DIR` | Project root | Absolute path where models/, data/, outputs/ live |
| `WC2026_CORS_ORIGINS` | `*` | Comma-separated allowed origins |
| `WC2026_LOG_LEVEL` | `INFO` | Logging verbosity |
| `WC2026_N_SIMULATIONS` | `10000` | Monte Carlo simulation count |

## Deployment

### Backend → Render

1. Push code to GitHub (models/, data/, outputs/ are gitignored — upload separately)
2. Create **Web Service** on Render, connect the repo
3. **Build command:** `pip install -r requirements.txt`
4. **Start command:** `uvicorn backend.main:app --host 0.0.0.0 --port $PORT`
5. Add environment variables from `.env.example`
6. Upload model artefacts via Render Disk:
   ```
   /app/models/lr_match_v2.pkl
   /app/models/scaler_match_v2.pkl
   /app/models/le_match.pkl
   /app/data/elo_wc26_teams.csv
   /app/data/squad_strength_features.csv
   /app/data/form_cache.json
   /app/data/group_members.json
   /app/outputs/*   (all generated CSVs)
   ```

### Frontend → Vercel

```bash
cd frontend

# Install Vercel CLI
npm i -g vercel

# First deploy (follow prompts)
vercel

# Set environment variables on Vercel
vercel env add NEXT_PUBLIC_API_URL production
# Enter: https://your-backend.onrender.com

vercel env add NEXT_PUBLIC_SITE_URL production
# Enter: https://your-app.vercel.app

# Production deploy
vercel --prod
```

**Or via Vercel Dashboard:**
1. Import project from GitHub
2. Framework: Next.js (auto-detected)
3. Root directory: `frontend`
4. Add environment variables in Settings → Environment Variables
5. Deploy
